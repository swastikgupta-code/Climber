# Climber
A game where you climb using physics. Here you can only use A and D keys to left and right respectively . To move up you need to press space key so that your player linear motion gets converted to angular motion . To reach the top you need to continously keep climbing without falling
# How to Play
play the game at https://swastikgupta-code.github.io/Climber/
# Controls
- A: to move left
- D: to move right
- Space: to hook to the top surface
# Tech Stack
- javascript
- webgpu
- html
- css
